# research/notes/ — working notes and synthesis

**Step 1 (Part A) · Lead: Karl**

Thinking, reading summaries, and synthesis-in-progress live here. These are *not* sources
— a claim in the report must trace to a file in `../sources/`, never to a note.

Commit little and often: a half-formed synthesis note is worth more on the record than a
polished one written from memory three weeks later. Negative findings ("the objection
about X turns out to be technically unfounded because…") belong here as much as positive
ones.

**Done** when the notes have distilled the primary sources into the claims that populate
the knowledge graph, with each claim pointing at the source(s) that back it.
